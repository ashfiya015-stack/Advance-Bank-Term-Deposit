# 📊 Advance Bank Term Deposit — Customer & Campaign Analysis

## 📌 Project Overview

This project analyzes customer and marketing campaign data from a bank to understand the factors influencing **term deposit subscription**.

The project combines **Exploratory Data Analysis (EDA), data visualization, business insights, and predictive analysis** to identify customer patterns and evaluate campaign effectiveness.

The goal is to transform raw banking data into actionable insights that can help improve customer targeting and marketing strategies.

---

## 🎯 Business Objective

The main objectives of this project are to:

- Understand customer demographics and behavior.
- Analyze factors associated with term deposit subscription.
- Evaluate the effectiveness of different contact methods.
- Study campaign contact frequency and call duration.
- Identify important relationships between numerical variables.
- Build a basic predictive model for subscription.
- Provide data-driven recommendations for improving marketing campaigns.

---

## 📂 Dataset

The dataset contains information about customers and their interactions with a bank marketing campaign.

### Key Features

| Category | Features |
|---|---|
| Customer Information | Age, Job, Marital Status, Education |
| Financial Information | Account Balance |
| Contact Information | Contact Method, Month, Day |
| Campaign Information | Duration, Campaign, Previous Contacts |
| Previous Campaign | Previous Outcome |
| Target | Term Deposit Subscription |

The target variable indicates whether the customer subscribed to a term deposit:

- `yes` → Customer subscribed
- `no` → Customer did not subscribe
